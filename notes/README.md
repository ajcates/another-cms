# Project Documentation Hub

Welcome to the central hub for all project-related documentation. This directory is designed to be the single source of truth for project plans, technical decisions, team processes, and more.

## Getting Started

If you are new to the project, the best place to start is the [**Onboarding Guide**](./Onboarding.md). It contains all the information you need to get your development environment set up and make your first contribution.

For information on our team's processes and how we work together, please refer to the [**Working Agreements**](./WORKING_AGREEMENTS.md).

## Table of Contents

### Project Phases

This section contains the documentation for each phase of the project lifecycle.

-   [**1. Discovery and Planning**](./1.%20Discovery%20and%20Planning/): Documents related to the initial project planning, scope definition, and requirements gathering.
-   [**2. Design**](./2.%20Design/): Contains technical and visual design documents, including UI/UX mockups and system architecture.
-   [**3. Development**](./3.%20Development/): Notes and plans related to the active development and implementation of features.
-   [**4. Testing and QA**](./4.%20Testing%20and%20QA/): Test plans, bug reports, and quality assurance documentation.
-   [**5. Deployment**](./5.%20Deployment/): Release plans, deployment checklists, and production environment details.
-   [**6. Maintenance and Iteration**](./6.%20Maintenance%20and%20Iteration/): Documentation for ongoing support, bug fixes, and planning for future versions.

### Living Documents

These documents are continuously updated and provide a record of our decisions and discussions.

-   [**ADRs (Architecture Decision Records)**](./ADRs/): A log of important architectural decisions. This is where you can find the "why" behind our technical choices.
-   [**Meeting Notes**](./Meeting%20Notes/): An archive of notes from team meetings.
-   [**Retrospectives**](./Retrospectives/): Summaries of our sprint and project retrospectives, capturing what we've learned and how we plan to improve.
