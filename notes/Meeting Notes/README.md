# Meeting Notes

This directory is for storing notes from all project-related meetings. Keeping a record of meeting discussions, decisions, and action items is crucial for maintaining alignment and ensuring that important information is not lost.

## Naming Convention

Please name your meeting notes files using the following format: `YYYY-MM-DD-Topic.md`. For example, `2024-10-27-Sprint-Planning.md`.

This convention makes it easy to find notes from a specific date or about a particular topic.
