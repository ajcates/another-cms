# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs). ADRs are short documents that capture important architectural decisions made during the project. Each record should describe the context of the decision, the decision itself, and the consequences of that decision.

Using ADRs helps to:
- Provide a clear history of technical decisions.
- Onboard new team members by explaining the "why" behind the system's architecture.
- Avoid repeating past mistakes.

A new ADR should be created for any decision that has a significant impact on the project's architecture. A good practice is to use a template for consistency. See `TEMPLATE.md` for an example.
